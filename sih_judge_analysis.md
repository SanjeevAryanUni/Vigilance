### 1.3 — Code Logic Errors (What's Visible)

1. **`detector.py` — Fallback path is dangerous:**
   ```python
   if os.path.exists(pt_path) or not os.path.isabs(pt_path):  # Line 57
       self.pt_model = YOLO(pt_path)
   ```
   The `or not os.path.isabs(pt_path)` means it will ALWAYS try to load a non-existent model from the internet on first run (Ultralytics auto-downloads), which:
   - Fails offline / on edge devices with no internet
   - Downloads a **generic** yolov8n.pt (COCO-trained), NOT an RDD2022-trained model
   - Silently gives wrong predictions (80 COCO classes vs 4 road damage classes)

2. **`database.py` — Conditional column definition at class body level:**
   ```python
   class Detection(Base):
       ...
       if GEOALCHEMY_AVAILABLE and IS_POSTGRES:
           geom = Column(Geometry(...))  # Line 60
   ```
   This **executes at import time before any database connection exists**. `IS_POSTGRES` is evaluated once from `DATABASE_URL` env var. If someone sets `DATABASE_URL` after import, the column is permanently wrong.

3. **`celery_app.py` — Empty `else` block:**
   ```python
   if not REDIS_URL:
       ...
   else:
       # EMPTY — code truncated
   ```
   When Redis IS available, the Celery app is **never created**. This means production mode (with Redis) is completely broken.

4. **`main.py` — `allow_origins=["*"]`:** Accepts requests from any origin with credentials enabled — a CORS misconfiguration that can be exploited.

5. **`main.py` — Deprecated `on_event` lifecycle:**
   ```python
   @app.on_event("startup")  # Deprecated in FastAPI 0.100+
   ```
   Should use `lifespan` context manager pattern.
